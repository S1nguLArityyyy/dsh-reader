# Dsh Reader

一个自己用的 EPUB 阅读器，桌面端（Windows）和手机端（Android）各一份，
通过**局域网**互相同步阅读进度与书籍，不依赖任何网盘或云账号。

- 桌面端：Electron + React，免安装，带一个局域网服务
- 手机端：Capacitor + React，单 APK 安装即用

## 功能

**阅读**

- 翻页阅读，支持单栏 / 双栏、字号、行距、字体、主题配色调节
- 目录跳转、全文搜索、阅读位置记忆
- 显示阅读进度、章节字数、剩余时间估算；手机端显示电量
- 支持「标记读完」：标记后显示 100%，取消标记可回到真实位置

**书库**

- 导入 EPUB（可整目录批量导入），自动提取封面与主色
- 按系列自动归组，支持手动调整；同一系列按卷号排序
- 搜索书名 / 作者 / 系列，多选管理、隐藏、删除
- 分组折叠，显示每组册数

**统计**

- 阅读日历与热力图，按月 / 按年查看
- 累计时长、平均时长、已读书籍数
- 时长按「书 + 日期 + 设备」分别记录，两台设备的时长相加

**局域网同步**

- 桌面端启动时自动开启局域网服务（端口固定 8787）
- 手机端填入电脑的局域网地址即可连接，双向交换阅读进度、时长与读完标记
- 书籍只从电脑流向手机，且只传手机缺少的那几本
- 记录按时间取新合并；手机端改动冲突时会提示选择保留哪一份，合并前两边都会留备份

## 快速开始

### 桌面端（Windows）

1. 下载 `DshReader-1.0.0.zip` 解压到任意位置（不要放在开发项目目录里）
2. 双击 `DshReader.exe`
3. 把书拖进窗口，或从「书库 → 导入」选择文件夹

数据和书籍都留在本机：

- 书库清单、进度、时长、设置：`%APPDATA%\Dsh Reader`
- 书籍文件：程序目录下的 `books\`

### 手机端（Android）

1. 安装 `DshReader-1.0.apk`（首次需允许安装未知来源应用）
2. 「书库 → 导入」选择手机里的 EPUB，或走局域网从电脑拉取

## 手机怎么连上电脑

桌面端启动后会在局域网里开一个 HTTP 服务，手机端要填的地址形如
`http://192.168.x.x:8787`，其中 `192.168.x.x` 是**电脑在局域网里的 IP**。

这个地址在程序里直接能看到，三种方法任选：

1. **桌面端侧边栏左下角**：显示「局域网 192.168.x.x:8787」，
   点开是「局域网服务」面板，里面有完整地址与最近收到的记录
2. **桌面端设置 → 局域网服务**：卡片里写了服务地址
3. **命令行**：执行 `ipconfig`，取当前上网网卡（一般是「以太网」或「WLAN」）的
   IPv4 地址，拼上 `:8787`

桌面端还会把地址写进 `%APPDATA%\Dsh Reader\lan.txt`。

注意：

- 手机和电脑必须连**同一个** WiFi 或路由器
- 防火墙弹窗要选「允许访问专用网络」
- 内网 IP 会变（重启电脑或路由器后），连不上时先看侧边栏地址是否变化
- 电脑关机或退出后服务即停止，手机连不上——服务由电脑提供

## 同步协议

两端约定很简单，方便自己排查：

| 接口 | 说明 |
| --- | --- |
| `GET /books.json?have=<哈希列表>` | 返回手机缺少的书，每本带内容哈希 |
| `GET /books/<文件名>` | 下载书籍文件（带字节级进度） |
| `GET /records` | 导出阅读记录，按内容哈希索引 |
| `POST /records` | 合并手机推来的记录，写入前先备份 |

合并规则：

- 进度按 `updatedAt` 取新
- 时长按（书, 日期, 设备）分别累计，同一键取较大值
- 双方自上次同步后都改动过则视为冲突，交由用户选择
- 键会先归一（手机的 `sha1:` 前缀与电脑的书目 id 互相对应），再按书 / 日期 / 设备去重

## 从源码构建

```bash
# 桌面端
cd DshReaderV2
npm install
npm run dev          # 开发模式
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1   # 打包并部署

# 手机端
cd DshReaderMobile
npm install
npm run android:apk  # 产出 android/app/build/outputs/apk/debug/app-debug.apk
```

桌面端打包需要 `JAVA_HOME`（JDK 21），手机端还需要 `ANDROID_HOME`。
